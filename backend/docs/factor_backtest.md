# 因子回测口径

## 调仓

`rebalance_freq` 支持 `1D`（每日）、`1W`（每周）、`2W`（每两周）和 `1M`（每月）。周从周一开始，双周以 1970-01-05 周一为固定锚点，月按自然月。每个新周期使用面板中首个市场交易日，而非固定 5/10/20 个交易日。

首次建仓发生在回测区间内第二个交易日，使用前一交易日信号；随后按日历周期调仓，均在开盘成交。非调仓日仍每日估值。缺少信号或因停牌、涨跌停不能成交的订单不在周期内自动重试。

## 因子方向

批量单因子回测和组合使用训练 IC 确定方向：优先读取 `segments.train.ic`，兼容旧记录顶层 `ic`。训练 IC 为负时执行 `-(原表达式)`，否则保持原表达式。不使用验证集、测试集或本次回测收益确定方向。

原始因子记录不改写。结果和汇总记录 `direction`、`training_ic`、`direction_source`、`original_backtest_expression`、`effective_expression`、`direction_applied`，避免后续组合重复反向。训练 IC 缺失或为零时保留表达式并明确记录原因，不能把此类记录解释为已经验证方向。

原始训练/验证指标仍按原表达式展示，因此负 IC 不会为了显示好看而变为正值。组合内用于优化的有符号指标与实际执行方向同步调整。

## 研究默认参数

| 参数 | 默认值 |
|---|---|
| TopK | 50 |
| 初始资金 | 100,000,000 元 |
| 佣金 `commission` | 0.0003，买卖两端 |
| 过户费 `transfer_fee` | 0.00001，买卖两端 |
| 印花税 `stamp_duty` | 0.0005，仅卖出 |
| 滑点 `slippage` | 0.001；压力测试可设为 0.002 |
| 最低佣金 `min_cost` | 5 元/笔 |
| 单票目标权重上限 `max_weight_per_stock` | 0.03 |

买入费用 = max(成交额 × 佣金率, 最低佣金) + 成交额 × 过户费率。

卖出费用 = max(成交额 × 佣金率, 最低佣金) + 成交额 × 过户费率 + 成交额 × 印花税率。

最低费用只作用于佣金。买入预算扣除相应费用后确定股数，交易明细分别记录三项费用和总费用。滑点反映在成交价格中；`cost` 统计佣金和税费，不另计已体现在价格中的滑点。

这些是用户指定的固定研究参数，不是按日期变化的历史税率表，也未实现随成交量变化的冲击成本。单票上限约束调仓目标；非调仓日价格变动和无法卖出可使实际权重偏离目标。

显式传入旧 `buy_cost` 或 `sell_cost` 时，该侧按旧的总费率和最低费用口径执行，不再叠加拆分费用；新页面只传拆分费用。原始历史结果不会自动重算。

## 页面指标

验证 IC、验证 ICIR、有效天数分别来自 `segments.valid.ic`、`segments.valid.icir`、`segments.valid.valid_days`。无验证集数据、null、非有限值都显示“—”。真实零值保留。页面不再按 ID、表达式或列表位置生成任何模拟指标。

回测与组合仅消费 `confirmed_factors.jsonl`。测试集在独立的因子确认任务中一次性筛选冻结候选，指标与结论落盘；不会在回测时重新评估。测试集仍不参与 PPO reward 或因子方向选择。详见 [因子确认说明](factor_confirmation.md)。
