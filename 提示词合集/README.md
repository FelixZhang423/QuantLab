# TradingAgents-CN 提示词合集

本目录按项目的多智能体投研流程整理核心提示词，便于阅读、复用和二次改造。

## 文件分类

- [01-分析师提示词.md](./01-分析师提示词.md)：技术面、基本面、新闻、社交情绪、中国市场分析师。
- [02-研究辩论提示词.md](./02-研究辩论提示词.md)：看涨研究员、看跌研究员、投资组合经理。
- [03-交易与风控提示词.md](./03-交易与风控提示词.md)：交易员、激进/中性/保守风险分析师、风险经理。
- [04-工具调用与结构化输出提示词.md](./04-工具调用与结构化输出提示词.md)：工具调用约束、Google 工具处理、最终信号 JSON 抽取。
- [05-反思记忆与通用约束提示词.md](./05-反思记忆与通用约束提示词.md)：初始请求、股票代码约束、反思记忆提示词。

## 阅读顺序

1. 先看 `01-分析师提示词.md`，理解项目如何要求 LLM 调工具获取真实数据。
2. 再看 `02-研究辩论提示词.md`，理解多空观点如何辩论。
3. 然后看 `03-交易与风控提示词.md`，理解如何从投研报告走向交易建议和风控裁决。
4. 最后看 `04` 和 `05`，它们是防止模型跑偏、抽取结构化信号、沉淀经验记忆的辅助层。

## 说明

- 以下内容是基于源码中的提示词整理成 Markdown 版本，保留主要变量占位符，例如 `{ticker}`、`{company_name}`、`{current_date}`。
- 源码里部分提示词由多个字符串拼接，本文档已按可读性合并。
- 这些提示词用于研究和学习，不构成投资建议。
