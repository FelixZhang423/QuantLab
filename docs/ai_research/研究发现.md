# AI 量化研究发现

## 核心判断

你们当前的主要缺口不是再造一个回测器，而是缺少一层“研究 Agent 编排层”：把自然语言目标转换成结构化研究任务，调用数据字典、因子生成、表达式校验、回测、统计审计和报告工具，并把每次实验沉淀为可检索的研究记忆。

## 研究证据

- Alpha-GPT / Alpha-GPT 2.0：最贴近“人和模型共同挖掘 Alpha”的产品形态。关键思想是人给出投资直觉，模型把直觉翻译成因子表达式，数值引擎评估后再把结果反馈给下一轮搜索。
- AlphaForge / AlphaAgent：说明 LLM 或 Agent 不能只生成单个公式，还要处理公式搜索、候选去重、因子组合、动态选择和 Alpha 衰减。
- FinGPT / BloombergGPT / FinBen：说明金融领域模型的价值主要体现在金融语料、任务定义、评测和领域适配，而不是让通用模型凭空预测价格。
- FinMem / FinRobot：说明金融 Agent 的重要组成是分层记忆、工具调用、多角色协作、可追溯流程和研究报告，而不是单轮聊天。
- Sentiment trading with large language models、Newsflow stock-return prediction：更适合用作“非结构化信息转成可回测信号”的证据，但必须严格处理发布时间、可得性和前视偏差。

## 落地优先级

1. 先做对话到研究任务 JSON 的编译器。
2. 再把现有因子生成和回测包装成受控工具。
3. 增加研究实验注册表和失败案例记忆。
4. 最后再做多 Agent 并发、文献 RAG 和自适应搜索。

## 主要风险

- LLM 生成的解释可能是事后合理化，不等于经济机制成立。
- 搜索大量候选会造成多重检验和回测过拟合。
- 新闻、公告和财务数据若按修订后数据读取，会产生隐性前视偏差。
- 只展示成功因子会造成选择性报告；拒绝候选和失败原因也必须保存。
