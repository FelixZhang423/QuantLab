# 知名量化系统与金融智能体

## 说明

本文件按公开知名度、行业影响力和与当前研究方向的相关性整理，不是严格的市场排名。不同系统解决的问题不同，不能简单比较谁的收益更高。

## 一、商业研究与金融信息系统

### Bloomberg Terminal / BloombergGPT

- 官网入口：[Bloomberg Professional](https://www.bloomberg.com/professional/)
- 相关论文：[BloombergGPT: A Large Language Model for Finance](https://arxiv.org/abs/2303.17564)
- 类型：金融信息终端 + 金融领域大模型。
- 可借鉴：数据和研究资料一体化、金融术语理解、专业用户工作流。
- 注意：Bloomberg 的数据授权、终端生态和商业资源是普通项目不具备的。

### AlphaSense

- 官网：[AlphaSense](https://www.alpha-sense.com/)
- 类型：企业级金融和市场情报搜索平台。
- 主要能力：公司研究、行业研究、新闻、电话会、研报和自然语言搜索。
- 可借鉴：用户用问题检索资料、按来源给出证据、把研究过程沉淀为工作流。
- 定位：更像金融研究搜索和情报平台，不等同于自动交易 Agent。

### Kensho

- 官网：[Kensho](https://kensho.com/)
- 类型：金融数据分析和企业 AI 平台，现属于 S&P Global 体系。
- 主要能力：金融文本处理、数据分析、事件研究、研究自动化和企业工具。
- 可借鉴：把金融数据、自然语言和分析工具结合，而不是只提供聊天界面。

### BlackRock Aladdin

- 官网：[Aladdin](https://www.blackrock.com/aladdin/)
- 类型：投资组合、风险和资产管理基础设施。
- 可借鉴：推荐或选股必须放在组合、风险、约束和执行环境中理解。
- 定位：不是 LLM Agent 产品，但可作为机构级投研和风险系统参照。

### LSEG Workspace / FactSet

- 官网：[LSEG Workspace](https://www.lseg.com/en/data-analytics/products/workspace)
- 官网：[FactSet](https://www.factset.com/)
- 类型：机构级金融数据、研究和投资工作台。
- 可借鉴：数据权限、来源追踪、研究工作流、组合分析和专业用户体验。

## 二、量化研究和回测平台

### WorldQuant BRAIN

- 官网：[WorldQuant BRAIN](https://www.worldquant.com/brain/)
- 类型：公式化 Alpha 研究平台。
- 主要能力：字段、算子、Alpha 表达式、模拟、质量指标和研究社区。
- 与当前方向的关系：最适合作为因子表达式研究平台的参照。
- AI 结合点：LLM 可以作为自然语言到表达式、字段解释、候选扩展和失败诊断层，核心模拟仍由确定性引擎完成。

### Microsoft Qlib

- 官方仓库：[microsoft/qlib](https://github.com/microsoft/qlib)
- 类型：开源量化研究平台。
- 主要能力：数据、特征、模型、训练、回测和实验管理。
- 可借鉴：量化研究流水线、数据和实验组织方式。
- 定位：量化研究基础设施，不是以对话为中心的金融 Agent。

### QuantConnect LEAN

- 官方仓库：[QuantConnect/Lean](https://github.com/QuantConnect/Lean)
- 官网：[QuantConnect](https://www.quantconnect.com/)
- 类型：开源算法交易引擎和云端量化平台。
- 可借鉴：策略代码、回测、实盘和数据接口的工程边界。

### OpenBB

- 官方仓库：[OpenBB-finance/OpenBB](https://github.com/OpenBB-finance/OpenBB)
- 官网：[OpenBB](https://openbb.co/)
- 类型：开源投资研究平台和数据接口层。
- 可借鉴：数据连接器、统一研究接口、开放生态和用户自定义工作流。

### Numerai

- 官网：[Numerai](https://numer.ai/)
- 类型：数据科学竞赛和众包 Alpha 平台。
- 可借鉴：模型提交、样本外评价、众包研究和激励机制。
- 定位：不是对话式 Agent，但代表外部研究者持续贡献模型的平台形态。

## 三、开源金融 Agent 和多 Agent 系统

### TradingAgents

- 论文：[TradingAgents: Multi-Agents LLM Financial Trading Framework](https://arxiv.org/abs/2412.20138)
- 官方仓库：[TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents)
- 类型：多 Agent 金融交易框架。
- 典型角色：基本面、技术面、情绪、新闻、看多/看空讨论、交易决策和风险管理。
- 可借鉴：角色分工、辩论式汇总、研究证据汇总和最终交易决策分离。
- 注意：开源演示中的回测结果不能直接等同于真实交易效果。

### FinRobot

- 论文：[FinRobot: An Open-Source AI Agent Platform for Financial Applications](https://arxiv.org/abs/2405.14767)
- 官方仓库：[AI4Finance-Foundation/FinRobot](https://github.com/AI4Finance-Foundation/FinRobot)
- 类型：金融应用 Agent 平台。
- 可借鉴：Agent 与金融工具接口，以及研究型应用而非单轮问答。

### FinAgent

- 论文：[A Multimodal Foundation Agent for Financial Trading](https://arxiv.org/abs/2402.18485)
- ACM 页面：[FinAgent ACM](https://doi.org/10.1145/3637528.3671801)
- 类型：多模态、工具增强型金融交易 Agent。
- 可借鉴：文本、图表和结构化数据共同进入研究流程，以及工具增强而不是只靠模型记忆。

### FinMem

- 论文：[FinMem: A Performance-Enhanced LLM Trading Agent](https://arxiv.org/abs/2311.13743)
- 类型：带分层记忆的交易 Agent。
- 可借鉴：短期记忆、长期记忆、角色状态和历史研究经验保存。

### QuantAgent

- 论文：[QuantAgent: Seeking Holy Grail in Trading by Self-Improving Large Language Model](https://arxiv.org/abs/2402.03755)
- 类型：自我改进型量化交易 Agent。
- 可借鉴：把历史结果用于下一轮策略改进。
- 注意：自我改进很容易变成适应历史数据，必须搭配严格样本外和多重检验控制。

### AI Hedge Fund

- 官方仓库：[virattt/ai-hedge-fund](https://github.com/virattt/ai-hedge-fund)
- 类型：开源演示型多 Agent 投资研究项目。
- 典型角色：不同分析师 Agent、投资组合经理和交易决策层。
- 可借鉴：把不同研究观点组织成多角色工作流。
- 注意：更适合作为 Agent 编排和产品演示参考，不应直接视为机构级投研系统。

### FinGPT

- 论文：[FinGPT: Open-Source Financial Large Language Models](https://arxiv.org/abs/2306.06031)
- 官方仓库：[AI4Finance-Foundation/FinGPT](https://github.com/AI4Finance-Foundation/FinGPT)
- 类型：金融模型层，而不是完整交易 Agent。
- 可借鉴：金融领域指令、情绪、文本处理和开源模型适配。

## 四、因子发现与研究 Agent

### Alpha-GPT / Alpha-GPT 2.0

- [Alpha-GPT](https://arxiv.org/abs/2308.00016)
- [Alpha-GPT 2.0](https://arxiv.org/abs/2402.09746)
- 定位：人机协同的 Alpha 假设和公式因子挖掘。
- 关键参照：自然语言想法、表达式生成、回测反馈、人工确认。

### AlphaForge

- [AAAI 页面](https://doi.org/10.1609/aaai.v39i12.33365)
- 定位：公式因子挖掘和动态因子组合。
- 关键参照：候选去重、因子组合和 Alpha 衰减。

### AlphaAgent

- [ACM 页面](https://doi.org/10.1145/3711896.3736838)
- 定位：LLM 驱动的 Alpha 搜索，关注正则化探索和 Alpha 衰减。
- 关键参照：避免 Agent 只重复生成相似表达式。

### Microsoft RD-Agent

- 官方仓库：[microsoft/RD-Agent](https://github.com/microsoft/RD-Agent)
- 定位：研发自动化和数据科学研究 Agent。
- 可借鉴：研究任务拆解、代码/实验循环、结果反馈和自动化研究。

## 五、系统之间的关系

```text
金融信息终端：Bloomberg / AlphaSense / Kensho / LSEG
        |
        v
研究数据与工具层：OpenBB / Qlib / QuantConnect / BRAIN
        |
        v
金融模型层：BloombergGPT / FinGPT / InvestLM
        |
        v
研究 Agent 层：FinRobot / FinMem / FinAgent / TradingAgents
        |
        v
因子与策略研究层：Alpha-GPT / AlphaForge / AlphaAgent / RD-Agent
        |
        v
组合、风险与执行层：Aladdin / LEAN / 自建回测和交易系统
```

## 六、最值得重点对标的系统

1. AlphaSense：金融研究搜索和证据呈现。
2. WorldQuant BRAIN：公式因子研究和表达式约束。
3. Microsoft Qlib：量化研究基础设施和实验管理。
4. TradingAgents：多 Agent 角色分工和观点汇总。
5. FinRobot：金融工具调用和研究型 Agent 平台。
6. Alpha-GPT 2.0：人机协同因子挖掘。
7. FinMem：研究记忆和历史状态。

## 七、需要避免的误区

- 把金融搜索平台当作交易 Agent。
- 把金融大模型当作因子发现系统。
- 把多 Agent 的角色数量当作系统能力。
- 把论文回测或开源演示结果当作可复制收益。
- 只比较模型名称，不比较数据、工具、时间协议和评估方式。
- 忽略风险、成本、容量和样本外稳定性。
