# 研究方法论整理

## 研究对象的四层划分

1. 自然语言研究目标：寻找高质量成长股、低回撤信号或行业中性 Alpha。
2. 可验证假设：明确经济机制、方向、期限和适用状态。
3. 数据和因子表达式：明确字段、算子、窗口、截面、时间点和缺失值规则。
4. 组合和交易结果：明确股票池、持仓数量、权重、换手、成本和风险约束。

LLM 最适合参与前两层，也可以辅助第三层；第四层需要确定性的量化引擎。

## 对话式研究循环

```text
用户问题
  -> 目标和约束澄清
  -> 检索论文、字段和历史实验
  -> 形成经济假设
  -> 生成受限因子表达式
  -> 语法与字段检查
  -> 样本内/样本外回测
  -> 成本、暴露、稳定性和多重检验审计
  -> 用户审阅
  -> 保留、拒绝或继续搜索
```

## Agent 应输出的结构化信息

- `task_id`：研究任务编号；
- `hypothesis`：经济假设；
- `data_requirements`：字段和时间范围；
- `candidate_expressions`：候选表达式；
- `evidence`：论文、数据和历史实验来源；
- `validation_plan`：验证方式；
- `risk_flags`：前视偏差、过拟合和暴露风险；
- `next_action`：下一步实验。

## 研究记忆

- 文献记忆：论文、机制、数据代理和适用条件；
- 字段记忆：字段含义、覆盖率、更新频率和可用时间；
- 实验记忆：表达式、配置、结果和版本；
- 失败记忆：拒绝因子、失败原因、重复结构和失效区间。

## Agent 边界

- 不凭空创造字段。
- 不绕过表达式白名单。
- 不使用当前信息重建历史可见信息。
- 不只返回成功候选。
- 不把语言解释当作因果证明。
- 不把单次回测结果写成无条件投资建议。
