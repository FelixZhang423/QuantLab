# 公开代码与开源平台

以下项目作为公开资料入口收集，不代表已经在当前项目中集成，也不代表其默认回测结果适用于当前数据。

## FinGPT

- 官方仓库：[AI4Finance-Foundation/FinGPT](https://github.com/AI4Finance-Foundation/FinGPT)
- 方向：开源金融大模型、金融数据和金融任务。

## FinRL

- 官方仓库：[AI4Finance-Foundation/FinRL](https://github.com/AI4Finance-Foundation/FinRL)
- 方向：深度强化学习量化交易框架、环境、策略和评估。

## FinRobot

- 官方仓库：[AI4Finance-Foundation/FinRobot](https://github.com/AI4Finance-Foundation/FinRobot)
- 方向：金融 Agent 平台、数据工具和研究型应用。

## Microsoft Qlib

- 官方仓库：[microsoft/qlib](https://github.com/microsoft/qlib)
- 方向：量化研究平台、数据、因子、模型和回测。

## Microsoft RD-Agent

- 官方仓库：[microsoft/RD-Agent](https://github.com/microsoft/RD-Agent)
- 方向：研发自动化 Agent 和数据科学研究流程。

## 项目定位区分

- FinGPT、BloombergGPT：金融语言模型。
- FinRobot：金融 Agent 和工具编排。
- FinRL：强化学习交易。
- Qlib：量化研究基础设施。
- RD-Agent：自动化研究过程。
- Alpha-GPT、AlphaForge、AlphaAgent：更直接对应因子发现。
